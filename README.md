# 1 — Data Cleaning & Visualization
Run `task_1_inspect_data.py`, `task_2_clean_data.py`, then `task_3_visualize_data.py`.
- Task 1 checks dimensions, types, missing values, duplicates, and numeric summaries.
- Task 2 removes exact duplicate rows, fills missing values, applies transparent bounds, and saves cleaned data.
- Task 3 creates a spend distribution, membership comparison, and visits-vs-spend plot.
The input dataset intentionally contains a few quality issues for practice. Validate any cleaning rule with domain experts when using real data.
